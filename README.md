**Nome:** Gabriella Ayres

## Repositório
**Link do Repositorio:**[Portfólio](https://github.com/Gabi-Ayres/Portifolio.git)

Este repositório contém o código do meu site portfólio pessoal, desenvolvido com o objetivo de apresentar o meu perfil, percurso académico, progresso técnico e, à medida que forem sendo desenvolvidos, os meus projetos.

O projeto foi criado como parte do meu processo de aprendizagem e evolução como programadora, com foco em **HTML, CSS e JavaScript**, seguindo boas práticas de estrutura, semântica e responsividade.

---

## Funcionalidades

- Página inicial com apresentação pessoal
- Secção **Sobre Mim**
- Secção **Educação**
- Secção **Progresso em Curso** com barras de progresso
- Secção **Projetos** com carrossel em JavaScript puro
- Página de **Contactos** com formulário funcional
- Layout **responsivo** (desktop, tablet e mobile)
- Integração com:
  - Google Maps
  - Font Awesome Icons

---

## Tecnologias Utilizadas

- **HTML5** – Estrutura semântica
- **CSS3** – Estilização, Flexbox e Media Queries
- **JavaScript (Vanilla)** – Carrossel de projetos e interação do formulário
- **Google Fonts**
- **Font Awesome**

## Principais Decisões Tomadas e Justificação

### Uso de HTML Semântico

- Foram utilizadas tags como <header>, <nav>, <main>, <section> e <footer> para melhorar:

   * Acessibilidade;

   * A organização do código;

   * A leitura por motores de busca.

### CSS Responsivo com Flexbox e Media Queries

- Optei por Flexbox pela sua flexibilidade na criação de layouts adaptáveis, complementado com Media Queries para garantir uma boa experiência em:

   * Desktop;

   * Tablet;

   * Telemóvel.

### JavaScript Vanilla

- O carrossel de projetos e a interação do formulário foram desenvolvidos sem bibliotecas externas para:

   * Consolidar fundamentos de JavaScript;

   * Reduzir dependências;

   * Melhorar o entendimento da lógica por trás das interações.

### Foco em Acessibilidade

* Uso de atributos alt em imagens

* Labels associados a inputs

* Contraste adequado de cores

* Conteúdo legível e estruturado

## Considerações Finais

Este portfólio foi desenvolvido para consolidar os meus conhecimentos em Front-End e demonstrar o meu percurso académico e técnico. Está em constante evolução e será atualizado com novos projetos à medida que os desenvolvo.
