# 🌐 Portfólio de Gabriella Ayres

Este repositório contém o código do meu **site portfólio pessoal**, desenvolvido com o objetivo de apresentar o meu perfil, percurso académico, progresso técnico e alguns projetos em Front-End.

O projeto foi criado como parte do meu processo de aprendizagem e evolução como programadora, com foco em **HTML, CSS e JavaScript**, seguindo boas práticas de estrutura, semântica e responsividade.

---

## Funcionalidades

- Página inicial com apresentação pessoal
- Secção **Sobre Mim**
- Secção **Educação**
- Secção **Progresso em Curso** com barras de progresso
- Secção **Projetos** com carrossel em JavaScript puro
- Página de **Contactos** com formulário funcional
- Layout **responsivo** (desktop, tablet e mobile)
- Integração com:
  - Google Maps
  - Font Awesome Icons

---

## Tecnologias Utilizadas

- **HTML5** – Estrutura semântica
- **CSS3** – Estilização, Flexbox e Media Queries
- **JavaScript (Vanilla)** – Carrossel de projetos e interação do formulário
- **Google Fonts**
- **Font Awesome**
